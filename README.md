# AB Creative — Website

الموقع الرسمي لـ **AB Creative**: استوديو تسويق وتصميم وموشن جرافيك وإدارة صفحات ومحتوى بالذكاء الاصطناعي (السعودية · السودان).

## التشغيل
موقع ثابت (HTML/CSS/JS) بدون أي بناء. افتح `index.html` أو انشره على Vercel / Cloudflare Pages / GitHub Pages.

## المجلدات
- `index.html` — الصفحة كاملة (عربي/إنجليزي، وضع ليلي ونهاري، Three.js + GSAP).
- `m/` — الصور والشعار.
- `v/` — الفيديوهات وصور الغلاف.
